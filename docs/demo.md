# Demo

1. Build and sign the app on a Mac for a physical iPhone.
2. Select Qwen3 0.6B and wait for its initial download.
3. Send a short prompt and observe the generated reply.
4. After download, test ordinary chat offline.
5. For image chat, select Qwen2.5 VL 3B and attach a photo.
6. Optional: configure Gmail, connect, search and tap a message to summarize.
